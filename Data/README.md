# Input data

Station CSV files are intentionally not committed to Git. Download the 45 source files from the archived Figshare v3 record by running this command from the repository root:

```bash
python download_figshare_data.py
```

Download a single station for a small test:

```bash
python download_figshare_data.py --station USW00013968
```

Source record: <https://doi.org/10.6084/m9.figshare.30370084.v3>
